## 正音 1.0.0 · 首个 Windows 桌面版

首个面向 Windows x64 的桌面版：发音评测、复习和笔记仍全部在本机运行，AI 讲解是可选的一层。

### 桌面版

- **两种安装方式**：NSIS 安装版（`zhengyin-1.0.0-win-setup.exe`，内置更新器）或免安装 zip（解压覆盖，手动更新）。
- **开箱即用**：随包携带 Node 26 与 uv，不用另装运行时；首次逐音素评测会下载约 1.2GB 模型。
- **数据在你手里**：首次启动可选旧数据文件夹、导入备份或全新开始；关窗口即退出，同一数据目录只允许一个进程。
- **未签名**：第一次运行会出现 SmartScreen 提示，点「更多信息 → 仍要运行」即可。

### AI（可选）

- **两种接法**：OpenAI 兼容 / Anthropic / Gemini 接口，或 Claude Code / Codex / Gemini CLI / Antigravity 本机命令行。
- **讲解与笔记**：词条页直接讲解当前词，把结论写成 `data/notes/` 下的笔记；笔记有独立编辑器，保存前会跑格式校验。
- **助教与整理**：AI 助教可以追问；命令行模式的「AI 整理」能按记录补笔记、更新档案，跑完列出改动并可撤销这次改动。
- **默认不发送**：未勾选同意不会发资料；密钥只存本机，界面只显示末四位。

### 发音工具

- 逐音素评测（替换 / 漏音 / 多音）、真人录音与 A/B 对比；41 个音素各有「怎么发」、例词和笔记页。
- 复习队列按真实录音证据排序；发音统计按发音部位铺成矩阵。
- 笔记分「讲音」和「讲词」两种范围，避免一篇讲词的笔记弹到所有含这个音的词上。

### 已知限制

- 本版只提供 **Windows x64**；手机、macOS / Linux 均不在支持范围，也不接云端 ASR。
- Windows 安装包**未签名**，SmartScreen 警告是预期行为；zip 版不自动更新。
- 安装版已接入更新器，但这是首个发布，**N→N+1 的真实升级验证要等下一版**。
- 它不是发音评分器：只测音素层面，音色、时长、重音和语调不评测。
