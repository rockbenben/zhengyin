如果你在用 1.0.0，升级前只确认一件事：浏览器模式现在要 Node 26（桌面版不用管，自带运行时）。其余不用迁移，装上新版就能接着练——这一版把「装、更新、找人帮忙整理记录」这条链路补完整了，也修掉几处会算错账的问题。

### 破坏性变更

- **浏览器模式不再支持 Node 24 及更老**：用浏览器模式的人（macOS、Linux，以及没装桌面版的 Windows）需要 Node 26 或更新；用旧版 Node 双击启动会被拦下并提示升级，升级前先到 nodejs.org 装 LTS 版即可。桌面版不受影响。

### 新增

- **AI 整理不再只限命令行**：用接口的现在也能让 AI 按你的记录补笔记、更新档案；接口只返回方案，应用检查过才保存，跑完不满意可以整批撤销。
- **手机上也能翻着看了**：打开局域网访问之后，同一 Wi-Fi 下的手机可以只读查词、看笔记和发音统计、听发音、看到期队列；录音和评分仍然只能在这台电脑上做。

### 变更

- **桌面版和设置页换了样子**：没有菜单栏了，打开和更换数据文件夹、检查更新、关于、退出都挪到「设置 → 应用 → 桌面版」；设置页分成应用、声音、AI 讲解、主题、搬家五组，一次只露一组。下好的更新点通知就能装，查完会告诉你有没有新版本；主题和降噪的偏好跟着桌面版保存，换端口、重启都不丢。

### 修复

- 录音、复习与数据的三处：跳过一张卡之后，迟到的录音结果不会再算到下一张头上；窗口切到后台时录音也会按时停，超长音频会直接提示；导入备份保留词条的创建时间，切换用户后旧页面迟到的写入会被拒绝，从 agy 切到 Claude Code 也不再传错模型名。

**怎么装**：只提供 Windows x64。安装版可以自动更新；免安装 zip 解压覆盖即可，不自动更新，也不需要另装 Node / uv——桌面版自带运行时，首次逐音素评测会下约 1.2GB 模型。安装包未签名，首次运行 SmartScreen 点「更多信息 → 仍要运行」。Release 资产里附了 SHA256SUMS，可以核对下载到的安装包。
