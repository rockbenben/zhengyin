# /θ/ 发成 /s/（舌尖没伸出来）

**一句话结论：** 舌尖必须**伸出来碰到上门牙**。缩在嘴里就是 /s/，没有中间状态。

> 中文里根本没有这个音，所以嘴会自动挑一个最近的替身——/s/。这是**没学过**，不是发音器官有问题，也跟大舌头小舌头无关。

## 音标与定位

| | |
|---|---|
| **/θ/** | 清齿擦音。think、thin、three、math、path |
| **/ð/** | 浊齿擦音，位置一模一样，只多了喉咙震动。this、that、mother、breathe |

同一个动作，只差声带震不震——练会 /θ/，/ð/ 顺手就有了。

## 常见误区

中文母语者三种典型替身，按常见程度排：

- **/s/**（最常见）：think → "sink"、thin → "sin"、mouth → "mouse"。舌尖缩在牙齿后面没伸出来。
- **/t/**：three → "tree"。舌尖伸对了地方，但堵死了没留缝，成了爆破音。
- **/f/**：three → "free"。用下唇代替了舌尖，听感接近但口型完全不同。

三种里第一种压倒性地常见，练的时候先按它来。

## 发音原理

**/s/ 和 /θ/ 的差别只有一处：舌尖在牙齿后面，还是在牙齿中间。**

- **/s/**：舌尖靠近上齿龈（门牙背后那块凸起），**不碰到**，留一条又窄又紧的缝。气流高速冲过，声音尖、亮、集中。
- **/θ/**：舌尖**往前伸，轻轻搭在上门牙的下缘**，舌面和牙齿之间留一条又宽又松的缝。气流散着出去，声音钝、闷、没那么响。

关键在**松**。/s/ 是高压水枪，/θ/ 是漏气的轮胎。很多人舌位对了但还是像 /s/，是因为绷得太紧。

舌尖伸出多少？**能被上下门牙轻轻咬住**的程度。夸张一点没关系，先建立肌肉记忆，熟了自然会收。

## 自检法

**看镜子（最直接）**

发 /θ/ 时对着镜子——**应该看得见一点舌尖**露在牙齿外面。看不见就是没伸出来，那发的是 /s/。

**咬舌头**

用上下门牙**轻轻咬住舌尖**，保持咬着的状态送气。这个姿势下你**不可能**发出 /s/——物理上就发不出来。先在这个极端位置上把音找到，再慢慢松开到自然位置。

**摸气流**

手掌放在嘴前 5 厘米：

- /s/ 的气流**又细又急**，集中打在一小块皮肤上
- /θ/ 的气流**又散又缓**，摊开在整个手掌上

## 对比训练

### 先在中文里感受"舌尖伸出去"

中文里没有 /θ/，所以没法直接对照。但可以感受**位置差**：

念中文的 **"丝"**，注意舌尖在哪——在门牙**背后**，够不到牙齿。
保持送气不停，把舌尖**慢慢往前推**，推到碰上门牙、再露出来一点。声音会从尖利变得钝闷。

那个钝闷的音就是 /θ/。**在"丝"和 /θ/ 之间来回滑动十次**，把这段距离走熟。

### 英文 minimal pairs

| /θ/ | /s/ |
|---|---|
| think | sink |
| thin | sin |
| thick | sick |
| thing | sing |
| path | pass |
| mouth | mouse |
| tenth | tense |
| both | boas |

词尾那几组（path/pass、mouth/mouse）尤其要练——**词尾的舌尖最容易偷懒缩回去**。

### 顺带练 /ð/

位置不变，加上喉咙震动。摸着喉咙念：

this、that、these、those、mother、father、brother、breathe

英语里最高频的那批词全在这儿，练它性价比最高。

## 阶段拆解

1. **咬着舌尖送气**，只发 /θθθθ/ 长音，不接任何元音。听到那个钝闷的摩擦声为止。
2. **松开牙齿**，舌尖保持在门牙下缘，继续发长音。声音应该没有变化——一变尖就是缩回去了。
3. **接元音**：/θi/、/θɪ/、/θɛ/，每次都从长音起头。这一步**不要借英文词当标签**——
   the 是 /ðə/、thee 是 /ði/，两个都是**浊**的 /ð/，正是第 7 步要跟 /θ/ 分辨的那一半；
   照着它们念，练的恰好是这篇要纠的那个混淆。
4. **单词**：think、thin、thick。**故意把开头拉长**：θθθ-ink。
5. **词尾**：path、mouth、both。这一步开始对镜子看——词尾最容易缩回去。
6. **对比串**：think-sink-think-sink 连读十遍，感受舌尖来回移动。
7. **句子**：I think this is the third thing. 里面有 /θ/ 和 /ð/ 两种，边说边摸喉咙分辨。
