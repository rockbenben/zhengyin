# /ɑ/ 和 /æ/——两个低元音，中文里一个都没有

**一句话结论：** /ɑ/ 是**嘴张大、舌头后缩、下巴掉下去**的音（box、father）；/æ/ 是**嘴角向两侧咧开、舌头前伸**的音（cat、glass）。舌头前后差得很远，不是"差不多的 a"。

## 这是怎么发现的，以及它有多确定

> 下面的次数来自**仓库自带的那份练习记录**——写这篇笔记时那个人自己的，不是你的。
> 保留它是因为这一节讲的不只是他，还有**这个工具的判定有多可信**，那部分对谁都成立。

那份记录里：**detox 那个元音 20 次被听成别的音，其中 14 次整条转写只错这一处**。

```
[d i t ɑ k s]  →  [d i t æ k s]     ← 其余六个音全对，只有这一个元音换了
```

真人录音（Merriam-Webster）过同一个模型转出的是 `d iː t ɑː k s`——**同一位置、同一个模型，
母语者是 ɑ，那份录音不是**。所以「这个元音跟母语者不一样」这件事是确定的。

**但"它是 /æ/"这个标签只有六成把握，我得说清楚。**

这篇笔记原来在这儿写过一句：「模型不可能连续十五次在一条干净的转写里恰好错同一个位置」。
那句论证是错的，而且错得挺蠢——**系统性偏置的定义就是每次都一样**。拿 16 条真人录音
（真人念的按定义就是对的）量下来：

| | 逐音素对上的比例 |
|---|---:|
| 辅音 | 41/42 = **98%** |
| 元音 | 15/22 = 68% |
| **其中低/中元音 ɑ æ ʌ ə ɔ ʊ** | **6/10 = 60%** |

而且错的方向很一致——**模型把低元音往 /æ/ 上拽**：

```
book  /bʊk/  →  b æ k      真人念的是 /ʊ/
cup   /kʌp/  →  k æ p      真人念的是 /ʌ/
```

**这一段对你同样适用**：工具报你 detox 的元音是 /æ/ 时，真实身份可能是 **/æ/、/ʌ/、/ʊ/**
里的任何一个——三个都不对，但**改法不一样**：/æ/ 是嘴角咧开了，/ʌ/ 是嘴张得不够，
/ʊ/ 是嘴圆了。下面那节「先自己定是哪一个」就是干这个的，**不靠模型**。

（对照：辅音那一档落在 98% 上，结论不用打折，见 [前后鼻音不分](n-ŋ-前后鼻音.md)。
低元音这一档只有 60%，所以这篇的标签要打折——**该打折的是标签，不是"这个音不对"这件事**。）

## 先自己定是哪一个（不靠模型）

**一、照镜子，两秒钟的事**

| 音 | 镜子里的嘴 |
|---|---|
| /ɑ/（对的那个） | **上下张开的椭圆**，下巴掉下去，像医生让你说"啊" |
| /æ/ | **横向拉宽的扁形**，嘴角明显往两边走，像忍着笑 |
| /ʌ/ | 半开，**嘴角不动、也不圆**，很短 |
| /ʊ/ | **嘴唇微微收圆**，开口最小 |

念一遍 detox，在"t-?-ks"那一下**定格**，看镜子。上下椭圆就对了。

**二、手指测张口度**

下巴张开能竖着塞进**两根手指** → /ɑ/。只塞得进一根：
- 嘴角同时往两边拉 → /æ/
- 嘴角没动 → /ʌ/
- 嘴唇有点圆 → /ʊ/

**三、拿你自己当参照物（最准的一条）**

**别跟母语者比，跟你自己比。** 连着录这三个：

```
de-TOX     de-TAX     de-TUCKS
```

后两个是我编的、不是真词，就是为了让你在自己的口腔里做出 /æ/ 和 /ʌ/。
录完回放，**听你的 detox 更像哪一个**——像 TAX 就是 /æ/，像 TUCKS 就是 /ʌ/，
都不像、而且开口比两个都大，那你本来就念对了，是模型在拽。

这一条为什么最可靠：它完全绕开模型，用的是**你自己的发音系统**当尺子。
模型分不清的那三个音，你自己的嘴分得清——只是没人告诉过你该注意哪里。

## 音标与定位

| 音 | 舌位 | 例词 |
|---|---|---|
| **/ɑ/** | 低、**后** | b**o**x /bɑks/ · det**o**x /ˈdiˌtɑks/ · f**a**ther /ˈfɑðɚ/ · h**o**t /hɑt/ · c**a**lm /kɑm/ |
| **/æ/** | 低、**前** | c**a**t /kæt/ · gl**a**ss /ɡlæs/ · bl**a**ck /blæk/ · b**a**d /bæd/ · m**a**p /mæp/ |

**注意拼写会骗人**：/ɑ/ 常常写成字母 **o**（box、hot、stop、doctor），/æ/ 才是典型的字母 **a**（cat、map、bad）。看到 box 里的 o 就照"哦"去念，或者反过来照字母 a 的印象去念 detox，都会掉进同一个坑。

## 常见误区

普通话里**这两个音一个都没有**，最接近的是「啊」——一个居中的低元音。所以中文母语者会拿「啊」去顶替两者，结果落在中间，模型（和人耳）听到的往往偏向 /æ/。

最常见的那一下：**detox 念成「dee-TAKS」**，那个 a 是 cat 的 a。正确的是「dee-TAHKS」，嘴要张开、舌头往后。

反过来的错也一样常见：把 glass 念成 /ɡlɑs/（英音是这样，**美音不是**），black 念成 /blɑk/。

## 发音原理

两个音的区别**主要在舌头前后，不在开口大小**——两个都是低元音，下巴都掉得很低。

**/ɑ/（后）**
1. 下巴放到最低，嘴张成一个纵向的圆
2. **舌根往后缩**，舌面整体压低，像医生让你说「啊——」看喉咙时那样
3. 嘴唇不圆不扁，自然放松

**/æ/（前）**
1. 下巴同样放低
2. **舌尖和舌面往前顶**，抵近下门牙
3. **嘴角明显向两侧拉开**——这是最好抓的一条，/æ/ 是个"咧嘴"的音，有点像在龇牙

一句话记：**/ɑ/ 是打哈欠的形状，/æ/ 是咧嘴的形状。**

## 自检法

**一、镜子看嘴角**——最直接。
念 cat 时嘴角该**明显向两侧拉开**；念 box 时嘴角**不动**，嘴张成上下方向的圆。
两个词念出来嘴角一样宽，就是没分开。

**二、手指压舌根**——把食指轻轻搭在下巴正下方那块软肉（舌根的位置）。
念 /ɑ/ 时那里会**鼓起来往下压手指**（舌根后缩下沉）；念 /æ/ 时几乎不动。

**三、交替快念**——`cat—cot—cat—cot`（/kæt/ /kɑt/）。
念得对的话，你会感到舌头在**前后来回**，像拉抽屉。只有下巴上下动、舌头不动，就是两个音发成了一个。

**四、录下来给工具听**——这个音正是评测抓得最准的一类。念 detox 三次，看音素条上第四个音是 ɑ 还是 æ。

## 对比训练

### 先在中文里感受"舌头前后"

中文没有这组对立，但有现成的前后感：

- 念「啊」拉长 → 再往「哎」的方向滑一点点（不要滑到底），**感受舌头往前顶**
- 念「啊」拉长 → 再往「喔」的方向滑一点点，**感受舌根往后缩**

前者的方向就是 /æ/，后者的方向就是 /ɑ/。**先把这两个方向分清楚，再进英文。**

### 英文 minimal pairs

只差这一个元音，其余完全相同：

| /æ/（前，咧嘴） | /ɑ/（后，张大） |
|---|---|
| c**a**t /kæt/ | c**o**t /kɑt/ |
| h**a**t /hæt/ | h**o**t /hɑt/ |
| b**a**ck /bæk/ | b**o**ck /bɑk/ |
| c**a**p /kæp/ | c**o**p /kɑp/ |
| st**a**ck /stæk/ | st**o**ck /stɑk/ |

每一对念五遍，**手指搭在下巴下方**确认舌根在动。

### 记录里的那个错法

| 错法 | 正确 |
|---|---|
| detox → 「dee-**TAKS**」（cat 的 a） | detox → 「dee-**TAHKS**」（box 的 o） |

顺带把整个词的另外两件事一起对上：重音在**第一个**音节（/ˈdi/），词尾 /ks/ 中间不许有元音——见 [词尾的辅音连缀](ks-词尾辅音连缀.md)。

## 阶段拆解

1. **只练两个元音**：`/æ/ — /ɑ/ — /æ/ — /ɑ/`，对着镜子，只盯嘴角开合
2. **加一个辅音**：`/kæ/ — /kɑ/`，再 `/tæ/ — /tɑ/`
3. **完整 minimal pair**：`cat — cot`，念到不用想就能切换
4. **回到整词**：`detox` /ˈdiˌtɑks/ — 第二个音节的元音是 box 的 o，不是 cat 的 a
5. **进句子**：`I need a dopamine detox.` 正常语速念，再录一次看音素条
