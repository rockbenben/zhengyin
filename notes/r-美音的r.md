# 美音的 /r/——舌尖不碰任何地方，也不许有摩擦

**一句话结论：** 舌尖**悬空**，不碰上颚、不碰齿龈、也不许擦出声音。碰到齿龈就是 /l/，只撅嘴不动舌就是 /w/，有摩擦声就是中文的「日」。

> 中文的 r（「日」「热」）舌尖靠近硬腭、带明显摩擦，是个**擦音**；英语的 /r/ 是**近音**，两者只是拼音字母长得一样。

## 音标与定位

**/r/** 齿龈后近音（approximant）。red、road、right、very、three、grow、around

它跟 [ɝ / ɚ 那个卷舌元音](ɝ-ɚ-儿化元音.md)是同一套舌头动作，区别只在**它是辅音**、要接着滑进后面的元音。练会一个，另一个大半就有了。

## 常见误区

按常见程度排：

- **用中文的「日」**：road 念成「肉的」，能听见明显的摩擦沙沙声。舌头离硬腭太近了。
- **念成 /l/**：rice → "lice"、road → "load"。舌尖顶上了齿龈。跟 [l/n](l-vs-n-边音与鼻音.md) 那篇不是一回事：那篇讲 l 和 n 的分别，这篇讲 r 不该碰到任何地方。
- **念成 /w/**：red → "wed"。嘴唇动作做对了（前突），但舌头完全没参与。
- **在辅音连缀里丢掉**：three → "tree"、grow → "go"。前一个辅音发完就直接进元音了。

## 发音原理

跟卷舌元音一样，两种做法都对，选一个能稳定做出来的：

1. **卷舌式**：舌尖微微上翘后卷，悬在口腔中部。
2. **束舌式**：舌尖朝下，舌体中后部隆起靠近硬腭后方。

不管哪种，三条铁律：

- **不接触**：舌尖跟上颚、齿龈都留着空隙。
- **不摩擦**：留的空隙要够大，气流顺畅通过，听不见沙沙声。这一条是跟中文 r 最大的分界。
- **唇要略微前突拢圆**——很多人只顾舌头忘了嘴唇，出来的 r 就不够「圆」。

发完立刻**滑**进后面的元音，中间不许停顿。

## 自检法

**听摩擦。** 把 red 的第一个音单独拖长三秒。**应该是安静的**——只有嗓音，没有沙沙声。听得见摩擦就是舌头太高了，往下降一点。这是区分英语 /r/ 和中文「日」最快的一招。

**查接触。** 拖长的时候舌尖碰到东西了吗？碰到齿龈 → 你念的是 /l/。用「先念 la、再念 ra」交替十次，感觉舌尖一次碰、一次不碰。

**照镜子看嘴唇。** 念 red 时嘴唇应该微微前突拢圆。如果嘴角是平的，音会发扁。

**指头测试。** 念 rice 的时候，把手指横放在唇前一厘米——嘴唇应该向前靠近它，但舌头在嘴里不该碰到任何东西。

## 对比训练

**先在中文里把「摩擦」和「不摩擦」分开。**

念中文「日」，注意舌头跟上颚之间那股摩擦。保持发声，**把舌头慢慢往下放一点点**，直到摩擦声消失、只剩一个圆润的嗡音——那就是英语的 /r/。来回做五次，记住那个「刚好没有摩擦」的位置。

**英文 minimal pairs —— /r/ 对 /l/（碰不碰齿龈）：**

| /r/ | /l/ |
|---|---|
| red | led |
| rice | lice |
| road | load |
| right | light |
| pray | play |
| grass | glass |

**/r/ 对 /w/（舌头有没有参与）：**

| /r/ | /w/ |
|---|---|
| red | wed |
| ray | way |
| rest | west |

**pray / play 和 grass / glass 这两对最值得练**：它们把 /r/ 放进辅音连缀，而那正是最容易被丢掉的位置。

## 阶段拆解

1. **找位置**：不出声，把舌头摆成卷舌或束舌式，确认舌尖悬空。
2. **拖长**：出声三秒，确认安静、没有沙沙声。
3. **加唇形**：保持舌位，把嘴唇微微前突，音会变圆。
4. **滑进元音**：/r/ → /ɛ/ → red。慢速十遍，重点是中间不许有停顿或摩擦。
5. **进连缀**：先分开念 「p...ray」，再逐渐缩短间隔直到 pray 成一拍。grass、three、grow 同法。
6. **进句子**：「**Read** the **red** book.」「**Three** **grey** **roads**.」
