# 词尾的 l 要收进去——feel 不是「菲欧」

**一句话结论：** 元音后面的 l 要做**两个动作**，缺一不可：舌根后部隆起（这是"暗"的来源）**并且**舌尖抵住上齿龈。中文母语者往往只做前一半，出来就是「欧」。

> 同一个字母 l，在元音**前**和元音**后**是两套动作。前面那套见 [/kl/ 辅音连缀](kl-click-辅音连缀.md)（清 L，舌尖迅速抵住再弹开）；这一篇讲后面那套。

## 音标与定位

音系学叫**暗 L（dark L / velarized L）**，符号 ɫ。它跟清 L 是同一个音素 /l/ 的两种读法，位置决定用哪一套：

- **清 L（clear L）**：出现在元音前，音节开头。light、clean、please、alive
- **暗 L（dark L）**：出现在元音后，音节结尾。feel、ball、milk、help、cold、people、little

## 常见误区

按常见程度排：

- **念成「欧」或「乌」**：feel → 「菲欧」、ball → 「波」、milk → 「谬克」。只做了舌根隆起那一半，舌尖压根没上去。这是最常见的一种，因为舌根隆起本身就很像一个圆唇元音。
- **整个省掉**：help → 「黑普」、cold → 「口的」。
- **加一个元音尾巴**：feel → 「菲了」、people → 「批坡了」。舌尖上去了，但放开的时候多送了一口气，变出一个音节。
- **用清 L 代替**：feel 的收尾念得又轻又前，跟 light 的 l 一样——听起来不像美音，但比前三种好得多。

## 发音原理

**两个动作同时做，顺序上舌根先起：**

1. **舌根（后部）向软腭方向隆起**——就像准备发中文「乌」时舌头往后堆的那个动作。这一步给出 l 的"暗"音色。
2. **舌尖同时抬起，抵住上齿龈**（上门牙后面那道硬棱）。
3. 气流从**舌头两侧**流出去——这一点跟清 L 一样，l 是边音（lateral）。
4. **抵住之后就停在那儿**，不要放开、不要送气。词尾的 l 是"收进去"，不是"弹出来"。

第 2 步是中文母语者最容易漏的：中文没有以 l 收尾的音节，舌尖没有这个习惯。

## 自检法

**摸舌尖的落点。** 念完 feel，**舌头停住别动**，感觉舌尖在哪里。

- 抵在上齿龈上 → 对。
- 悬在半空、或者贴在下齿背 → 你念的是「欧」，l 根本没发出来。

这是最硬的一条检查，因为它验的正是最常漏掉的那一步。

**数音节。** feel 是**一个**音节，拍一下手。如果你念出了两拍（「菲-欧」或「菲-了」），就是多出了元音。

**镜子看嘴唇。** 念 feel 的收尾时嘴唇**不该撅圆**。撅圆了说明你在发「欧」。

**捂嘴测试。** 抵住齿龈之后用手轻捂嘴，声音应该还能从舌头两侧走、闷闷地持续着——那证明是边音，不是元音。

## 对比训练

**先在中文里感受「舌尖收上去」。**

中文没有 l 收尾的音节，所以给不出中文的 minimal pair——能给的是那个**落点**：

念中文「了」（le），舌尖是碰到齿龈的。现在只念前半段：**舌尖碰上齿龈就停住，不要放开、不要带出后面的元音**。那个卡住的状态，就是词尾 l 的收尾。

再对照：念中文「欧」，舌尖是躺平的、什么都没碰到。两个来回念，感觉舌尖"上去"和"不上去"的分别。

**英文对照 —— 有没有把 l 收进去：**

| 有词尾 /l/ | 没有 |
|---|---|
| feel | fee |
| sail | say |
| mail | may |
| tool | two |
| bowl | bow |
| whole | who |

**清 L 对暗 L（同一个字母，两套动作）：**

| 元音前（清 L） | 元音后（暗 L） |
|---|---|
| **l**eaf | fee**l** |
| **l**ate | ta**ll** |
| **l**ow | o**ld** |

**最难的是 l 后面还有辅音的那些**：milk、help、cold、self。舌尖要先抵住齿龈，再从那儿接到下一个辅音，中间不许掉出元音。

## 阶段拆解

1. **只练落点**：不出声，把舌尖抵上齿龈、舌根同时后堆，保持三秒。这个姿势本身就是暗 L。
2. **加声音**：保持姿势出声，拖三秒，是一个闷闷的持续音。用手捂嘴确认声音还在。
3. **从元音滑进去**：`fee` → 舌尖抬上去 → `feel`。慢速十遍，每遍念完都检查舌尖落点。
4. **对照没有 l 的**：feel / fee 交替十遍。
5. **加后接辅音**：feel → milk（l 之后接 k）。重点是 l 和 k 之间**不许有元音**。help、cold 同法。
6. **进句子**：「I **feel** **cold**.」「**Tell** them **all**.」
