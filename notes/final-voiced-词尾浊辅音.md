# 词尾的浊辅音不许把喉咙关掉——bed 不是 bet

**一句话结论：** 词尾的 b d ɡ v ð z ʒ dʒ 要**一直震到底**。喉咙提前关掉，它们就分别变成了 p t k f θ s ʃ tʃ——而那往往是另一个词。

> 中文的音节只能以元音、n、ng 收尾，从来没有"辅音收尾还要带着声带震动"这回事。这是**没学过**，不是嘴笨。

## 音标与定位

**词尾的浊阻塞音**（塞音 / 擦音 / 塞擦音）：

| 浊（该有的） | 清化之后变成 | 例 |
|---|---|---|
| /b/ | /p/ | cab → cap |
| /d/ | /t/ | bed → bet、hard → heart |
| /ɡ/ | /k/ | bag → back、dog → dock |
| /v/ | /f/ | leave → leaf、save → safe |
| /ð/ | /θ/ | breathe → breath |
| /z/ | /s/ | eyes → ice、buzz → bus |
| /dʒ/ | /tʃ/ | badge → batch、ridge → rich |

**鼻音和流音不在此列**（m n ŋ l r）：它们本来就一直是浊的，没有清化这回事。

这一条跟[词尾的辅音连缀](ks-词尾辅音连缀.md)是同一个大问题的两半：那篇管「两个辅音都要发出来、中间不许有元音」，这篇管「最后那个不许把喉咙关掉」。

## 常见误区

- **整个清化**：bed → "bet"、bag → "back"、is → "iss"。最常见。听感上像是词换了。
- **补一个元音**：bed → 「拜德」、bag → 「拜格」。为了保住浊音，尾巴上多送一个 /ə/——这一下把单音节变成了两个音节，比清化还明显。
- **干脆吞掉**：bed → 「拜」、leave → 「里」。
- **只有在句末才出错**：句中连读时往往没问题（bed and → 「拜德恩」自然带出浊音），一到句末单说就清化了。所以自检要**单独念这个词**，不要放在句子里。

## 发音原理

浊辅音的"浊"来自**声带在震**。词尾要守住它，关键是**顺序**：

1. 发到最后那个辅音时，**先把声带的震动送出去**，再做口腔的封闭 / 摩擦。
2. **封闭之后不要急着放开**，也不要用力送气——一送气就清化了。
3. 收尾时喉咙是**慢慢停**的，不是一刀切断。

一个可操作的替代描述：**词尾浊辅音听起来"软"，清辅音听起来"脆"**。脆是因为有一股爆破气流，软是因为没有、而且带着嗡声。

还有一条英语里真实存在的线索：**浊辅音会让前面那个元音变长**。bed 的 /ɛ/ 明显比 bet 的长。很多母语者其实主要靠这个长度差在分辨——所以**把前面的元音拖足**，比死抠喉咙更容易做对。

## 自检法

**捂耳朵。** 双手捂住两只耳朵，交替念 bed / bet：

- **bed** 的收尾，头骨里能听见一段低沉的嗡声。
- **bet** 没有，只有一下气声。

这是最硬的一条——声带震动是通过骨头传导的，捂上耳朵反而听得更清楚。

**摸喉咙。** 手指按住喉结念 bag，最后那个 /ɡ/ 应该还在震。震动在辅音之前就停了，就是清化了。

**数音节。** bed 是**一拍**。念成「拜德」是两拍——说明你为了保住浊音多加了一个元音，那是另一种错。

**量元音长度。** 慢速交替念 bed / bet，注意中间那个元音：bed 的应该明显更长。两个一样长的话，多半两个词你念的是同一个。

## 对比训练

**先在中文里找到"喉咙一直震"的感觉。**

中文里没有浊辅音收尾，所以给不出中文的 minimal pair——能给的是那个**动作**：

念中文「妈」，把最后的元音一直拖着，手按喉结感觉震动。**保持震动不断**，同时把双唇轻轻合上——不要送气、不要放开。合上之后喉咙里那段还在响的嗡声，就是词尾 /b/ 的感觉。
换成舌尖抵齿龈，就是 /d/；换成舌根抵软腭，就是 /ɡ/。

**英文 minimal pairs —— 清化就变成另一个词：**

| 浊（守住） | 清（清化后） |
|---|---|
| bed | bet |
| bag | back |
| cab | cap |
| leave | leaf |
| save | safe |
| eyes | ice |
| badge | batch |
| hard | heart |
| prize | price |

**eyes / ice 和 prize / price 这两对最值得练**：/z/ 结尾出现在复数、第三人称、be 动词上，是英语里最高频的词尾之一。

## 阶段拆解

1. **只练收尾**：从中文「妈」的拖长元音出发，保持震动合上双唇 → /b/。舌尖版 → /d/，舌根版 → /ɡ/。各十次，全程手按喉结确认。
2. **配元音**：/ɛ/ + /d/ = "ed"，前面加 b 就是 bed。慢速十遍，每遍捂耳朵确认有嗡声。
3. **成对交替**：bed / bet 各五遍，注意两件事——收尾有没有嗡声、前面元音是不是更长。
4. **换到擦音**：leave / leaf、eyes / ice。擦音的浊比塞音更难守，因为气流一直在走。
5. **单独念，不要放句子里**：句中连读会自动带出浊音，掩盖问题。要在**句末**或者单说时检查。
6. **进句子**：「Put it on the **bed**.」「I'll **leave** now.」「Close your **eyes**.」
