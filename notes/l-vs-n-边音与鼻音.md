# l / n 不分（边音 vs 鼻音）

**一句话结论：** 舌尖位置完全一样，区别只在气流走鼻子还是走舌头两侧。

> 这是方言习惯（西南官话及部分南方方言）造成的，**不是生理缺陷**，可以彻底纠正。

## 原理

两个音的舌尖都抵住上齿龈（上门牙背后那块凸起的硬肉），唯一的差别是气流通道：

- **N（鼻音 nasal）**：口腔通道完全堵死，气流**只能从鼻腔出来**
- **L（边音 lateral）**：鼻腔通道关闭，气流**从舌头两侧流出**

## 自检法：捏鼻子测试（Pinch Test）

最直观的对错判断：

- **测 N**：持续发"恩——"，然后捏住鼻子。声音瞬间憋停、鼻腔里感到胀气 → N 发对了。
- **测 L**：舌尖顶住上齿龈发"勒——"的长音，然后捏住鼻子。声音**毫无变化**、依旧顺畅 → L 发对了（气流走口腔，捏鼻子不影响）。

> **发 L 时一捏鼻子声音就断了，说明你实际发的是 N。**

## 舌头的"胖瘦"（物理阻断法）

舌尖位置一样，所以要靠**舌头形状**来控制气流：

- **N 用"胖舌头"**：舌头放松摊平，舌尖连同前部边缘**全面贴紧**上颚，像盖子一样把口腔严严实实封死，逼气流走鼻子。
- **L 用"瘦舌头"**：舌头稍微用力，变得**尖锐紧致**。只有舌尖一点死死顶住上齿龈，舌头两侧主动**塌下来**离开牙齿，留出两条缝，让气流从嘴角两边跑出去。

## 对比训练（Minimal Pairs）

能用捏鼻法准确发出单个 N 和 L 之后再练。**夸张地放慢速度。**

先在母语里感受区别：

| N | L |
|---|---|
| 脑 nǎo | 老 lǎo |
| 南 nán | 蓝 lán |
| 女 nǚ | 吕 lǚ |
| 牛 niú | 流 liú |

再练英文（美音）：

| N | L |
|---|---|
| **N**ight /naɪt/ | **L**ight /laɪt/ |
| **N**o /noʊ/ | **L**ow /loʊ/ |
| **N**ine /naɪn/ | **L**ine /laɪn/ |
| S**n**ip /snɪp/ | S**l**ip /slɪp/ |
| S**n**ack /snæk/ | S**l**ack /slæk/ |

**nine 那一行值得多念几遍**：两个 /n/，词尾那个最容易吞掉，而 line 的词尾也是 /n/ ——
两个词只差开头一个音，剩下的完全一样，正好把注意力逼到该在的地方。

> 这一行原来是 need / lead，换掉了。lead 是**同形异读词**（heteronym）：词典给的主读音
> 是「铅」/lɛd/，「带领」那个 /liːd/ 只是备选。把它建成词条来练的话，这个工具会对着
> /lɛd/ 给你打分，照这张表念出来的 /liːd/ 反而算错。挑对比词时留意这类词。

## 练习建议

前期加两个外部提示帮助建立感觉：

- 每次发 **N** 都**摸一下鼻梁**，确认有震动
- 每次发 **L** 都刻意**咧开嘴角**（保持微笑口型），确保气流从脸颊两侧流出
