# /v/ 中文里没有——very 不是 wery，也不是 fery

**一句话结论：** 上门牙**轻咬下唇**，气从缝里挤出去，同时**喉咙震**。牙不碰唇就成了 /w/，喉咙不震就成了 /f/。

> 中文的声母表里没有 /v/（有些方言的「万」接近，但普通话没有），所以嘴会自动挑替身。这是没学过，跟舌头灵不灵没关系。

## 音标与定位

**/v/** 浊唇齿擦音（voiced labiodental fricative）。very、have、love、five、river、of

它和 **/f/** 是同一个口型、同一股气流，**只差喉咙震不震**——跟 /θ/ 和 /ð/ 的关系一模一样。练会一个，另一个只是加减一个动作。

## 常见误区

按常见程度排：

- **念成 /w/**：very → "wery"、vest → "west"。嘴唇撅圆了、上牙根本没碰下唇。这是最常见的一种，因为中文的「乌」口型很顺手。
- **念成 /f/**：very → "fery"、have → "haf"。口型对了，但喉咙忘了震。尤其容易出现在**词尾**：love、have、five 的收尾常常被清化成 /f/。
- **干脆吞掉**：of、have 在句子里念得很轻，直接没了。

## 发音原理

1. **上门牙轻搭在下唇内侧**——是「搭」不是「咬」，用力咬会把气流堵死。
2. **气从牙唇之间的缝里持续挤出**，是擦音，不是爆破，可以一直发下去。
3. **喉咙同时震动**。这是唯一跟 /f/ 不同的地方。

嘴唇**不撅圆、不前突**——一撅就成了 /w/。

## 自检法

**摸喉咙。** 手指按在喉结上，先拖长发 /f/（像放气的「呼——」），再不改口型加上声音变成 /v/。手指下面从不震到震，那一下就是 /v/。分不出来的话，交替念 fan / van 各五遍，感觉手指。

**照镜子看上牙。** 念 very 的第一个音，镜子里应该看得见**上门牙压在下唇上**。如果看到的是撅圆的嘴唇、牙齿藏在里面，你念的是 /w/。

**手背放在嘴前。** /f/ 的气流强、吹得手背发凉；/v/ 因为声带在震，气流明显弱一些。词尾的 love 如果吹出一股强气，说明被清化成 /f/ 了。

## 对比训练

**先在中文里找到起点。** 中文没有 /v/，但有 /f/——「飞」「非」的声母就是。

念中文「飞」，停在声母上别急着放元音，保持上牙压着下唇、气一直擦出去；然后**加上喉咙的震动**。从「飞」的 f 到 v，中间只隔这一个动作。

**英文 minimal pairs —— /v/ 对 /w/（管口型）：**

| /v/ | /w/ |
|---|---|
| vest | west |
| vet | wet |
| veil | wail |
| vine | wine |

**/v/ 对 /f/（管喉咙震不震）：**

| /v/ | /f/ |
|---|---|
| van | fan |
| very | ferry |
| vault | fault |
| leave | leaf |
| save | safe |

**leave / leaf 和 save / safe 这两对最值得练**：它们把问题放在**词尾**，而词尾正是最容易被清化的位置。

## 阶段拆解

1. **只练口型**：不出声，对着镜子把上门牙搭上下唇，保持三秒。确认看得见牙。
2. **加气流**：保持口型吹气，发出持续的 /f/，能吹多久吹多久。
3. **加喉咙**：气流不停，中途按住喉结，让它开始震——/f/ 就变成了 /v/。来回切换五次。
4. **配元音**：/v/ + e = ve，接上 -ry 就是 very。慢速十遍。
5. **搬到词尾**：love、have、five。重点是**收尾时喉咙不许提前停**，手背放嘴前确认没有强气流。
6. **进句子**：「I **have** **five**.」「I **love** it.」——连读时 have 和 five 的 /v/ 都要守住。
