# Dopamine Detox

**一句话结论：** 两个词都是**重音在最前面**，`dopamine` 的词尾是「**meen**」不是「**mine**」，`detox` 的 `-ks` 两个辅音之间**不许有元音**。

| | 音标 | 音节 |
|---|---|---|
| **dopamine** | /ˈdoʊpəˌmiːn/ | 3（DOH-puh-meen） |
| **detox** | /ˈdiˌtɑks/ | 2（DEE-toks） |

> ⚠️ CMUdict 里 `dopamine` 这条**是错的**（写成 `D AA1 P AH0 M AY2 N`，即 "DAH-puh-mine"）。已在 `server/src/analysis/lookup.ts` 的修正表里改掉——不改的话你念对了工具反而报你发错。证据见那里的注释。

## 常见误区

**dopamine —— 三个坑，中文母语者基本全踩**

1. **词尾念成「mine」**（最常见）。看到 `-ine` 就按 nine / fine / wine 的规律读成 /aɪn/。但化学后缀 `-amine` 一族**全都是 /-miːn/**：histamine、amphetamine、melamine、ketamine 都是。念成 "多巴迈恩" 是错的。
2. **三个音节读得一样重**：「多-巴-明」。中文每个字都有完整声调和时长，英语不是——`dopamine` 只有第一个音节重，中间那个 `pə` 要**轻到几乎听不见**。
3. **首元音丢掉滑动**：`/doʊ/` 是从 /o/ 滑向 /ʊ/、嘴唇边滑边收圆的**双元音**，不是一个固定的「都」或「欧」。

**detox —— 两个坑**

4. **词尾 `-ks` 中间加元音**：念成「dee-tock-**si**」，两个音节变三个。跟 [kl 辅音连缀](kl-click-辅音连缀.md) 是同一个毛病，只是位置不同：那篇讲词首的 /kl/，这里是**词尾的 /ks/**。
5. **重音跑到后面**：念成 de-**TOX**。名词 detox 重音在**前**（DEE-toks）。动词 detoxify 才是 /dɪˈtɑksɪfaɪ/、重音在后。

## 发音原理

### dopamine 的词尾：/miːn/

嘴角向两侧**拉平**（像在笑），舌面抬高靠前，音**拉长**。跟 machine、marine、routine 的收尾完全一样。

对比一下你的嘴：
- /miːn/ ——嘴角横向拉开，从头到尾**不动**
- /maɪn/ ——嘴先张大，然后下巴合上、舌面往上滑，**口型在变**

**口型在变就错了。** 照镜子最准。

### 中间那个 /ə/：越轻越对

`pə` 里的 /ə/ 是英语里最放松的音——嘴唇舌头都不使劲，时长短到只有重音节的三分之一。中文里没有这种"半个字"，所以本能会把它读成完整的「巴」。

**练法**：先只念 `DOH—————meen`，把中间彻底省掉。然后往缝里塞一个几乎不出声的 /p/ + 极轻的 /ə/。宁可太轻，不要太重。

### detox 的 /ks/：一次收尾，不是两个音节

`k` 和 `s` 之间**不能有任何声音**。做法是：

1. 舌根顶住软腭把气堵住（这是 /k/ 的姿势）
2. **别爆开**，直接把舌根松开一点点，让气流从舌尖和上齿龈之间擦出去（这是 /s/）
3. 全程嘴唇不动、下巴不动

关键在**第 2 步不要爆破**。一爆破就必然带出一个元音，「克」就冒出来了。

## 自检法

**数音节（最直接）**

手指敲桌子，一个音节敲一下：

- `dopamine` 敲 **3** 下：**DOH**-puh-meen
- `detox` 敲 **2** 下：**DEE**-toks

`detox` 敲出 3 下就是 /ks/ 中间加了元音。

**照镜子看词尾**

念 `dopamine` 的最后一个音节，看嘴：口型**从头到尾不变**才对。变了就是念成了 mine。

**摸下巴**

念 `detox` 时手指搭在下巴上。**该沉两次**——两个音节各一次，而且 `toks` 那次沉得更深：
它的元音是 /ɑ/（低元音，下巴要开），`DEE` 的 /i/ 是高元音，下巴几乎不动。
**第三次动才是问题**：那说明 `-ks` 中间塞进了元音，跟上面「敲出 3 下」测的是同一件事。

## 对比训练

### 先在中文里感受"辅音直接收尾"

中文没有 /ks/ 收尾，但有个接近的感觉：念「**克**」，然后**只做口型、不出声**——舌根顶上去、憋住、不放开。保持这个憋住的状态，把舌尖挪到上齿龈送气，变成「丝」的气流。

`k → s` 中间没有任何声音，这就是 /ks/。

### -ine 的两种读法

| /-iːn/（拉平不动） | /-aɪn/（口型在变） |
|---|---|
| dopam**ine** | m**ine** |
| mach**ine** | n**ine** |
| mar**ine** | f**ine** |
| rout**ine** | w**ine** |
| caff**eine** | sh**ine** |

左边一列连着念五遍，感受嘴角一直是拉开不动的。

### 词尾 /ks/

detox、box、fix、six、tax、mix、complex、relax

每个都**数音节**：全部是 1 或 2 个音节，没有一个多出来。

### 重音位置

| 重音在前（名词） | 重音在后（动词） |
|---|---|
| **DE**-tox | de-**TOX**-i-fy |
| **RE**-cord（唱片） | re-**CORD**（录制） |
| **PRO**-gress（进展） | pro-**GRESS**（前进） |

## 阶段拆解

1. **只练词尾 /miːn/**：meen—— 拉长，照镜子确认口型不变。再对比 mine，感受区别。
2. **只练 /ks/**：ks—— 舌根憋住、不爆破、直接擦出去。中间不许有声音。
3. **拼 dopamine**：先 `DOH…meen`（跳过中间），再塞进极轻的 `pə`。敲桌子确认 3 下。
4. **拼 detox**：`DEE` + `toks`。敲桌子确认 2 下，手指搭下巴确认只沉一次。
5. **连起来**：DOH-puh-meen DEE-toks。两个词的重音都在最前面，读起来是**强-弱-弱 强-弱**的节奏。
6. **放进句子**：I'm doing a dopamine detox this week. 整句里 dopamine 和 detox 各只有一个重音峰。
