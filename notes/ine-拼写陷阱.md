# 词尾 -ine：什么时候读 /aɪn/，什么时候读 /iːn/

**一句话结论：** 看到 -ine 别条件反射念 /aɪn/。**单音节词**才读 /aɪn/；**多音节的外来词**（尤其重音不在 -ine 上的、以及来自法语的）大多读 **/iːn/**。

这不是发音动作的问题——你的 /iː/ 和 /aɪ/ 都发得出来。这是**看拼写猜读音时按错了规律**：从 nine / fine / wine 外推出去，结果 machine 念成"马-掐-恩"。

## 两组词，两个读法

### 读 /aɪn/ —— 基本都是单音节的本族词

fine /faɪn/ · nine /naɪn/ · wine /waɪn/ · line /laɪn/ · mine /maɪn/ · dine /daɪn/ · shine /ʃaɪn/ · spine /spaɪn/

多音节里也有，但**重音必须落在 -ine 那个音节上**：
divine /dɪˈvaɪn/ · combine（动词）/kəmˈbaɪn/ · define /dɪˈfaɪn/

### 读 /iːn/ —— 多音节外来词（法语来源居多）

| 词 | 音标 | 重音 |
|---|---|---|
| machine | /məˈʃiːn/ | 在 -ine |
| routine | /ruˈtiːn/ | 在 -ine |
| marine | /məˈriːn/ | 在 -ine |
| caffeine | /kæˈfiːn/ | 在 -ine |
| magazine | /ˈmæɡəˌziːn/ | 在第一节 |
| gasoline | /ˈɡæsəˌliːn/ | 在第一节 |
| vaccine | /vækˈsiːn/ | 在 -ine |
| cuisine | /kwɪˈziːn/ | 在 -ine |
| **dopamine** | /ˈdoʊpəˌmiːn/ | 在第一节 |

### 还有第三种：读 /ən/（弱读）

engine /ˈɛndʒən/ · medicine /ˈmɛdəsən/ · determine /dəˈtɝmən/ · imagine /ɪˈmædʒən/ · genuine /ˈdʒɛnjəwən/

这一组的 -ine **完全不重读**，元音塌成 /ə/——就是[弱读音节要塌下去](ə-元音弱化.md)讲的那个音。
engine 念成"恩-真"就对了，念成"恩-掐-恩"或"恩-金恩"都不对。

> 有些词典把这一档记成 /ɪn/。**按 /ə/ 练**：这个工具的词典（CMUdict）上面五个词全是 /ə/，
> 而 /ə/ 和 /ɪ/ 是两个会被判开的音（/ə/ 只跟 /ʌ/ 归并），照 /ɪn/ 念会记一处替换错。

## 怎么判断（够用的经验规则）

按这个顺序问自己：

1. **是单音节吗？** → 读 /aɪn/。（fine、nine、wine）
2. **是不是一眼看去像外来词 / 科技词 / 法语词？** → 大概率 /iːn/。
   （machine、routine、cuisine、vaccine、dopamine、—ine 结尾的化学名几乎全是 /iːn/：
   morphine、nicotine、caffeine、histamine…）
3. **是不是一个常见动词或形容词，重音在最后？** → /aɪn/。（divine、define、combine）
4. **-ine 完全不重读、听着像被吞掉？** → /ən/。（engine、medicine、imagine、adrenaline）

> **adrenaline 是第 2 条的例外，而且是按顺序问下来必然撞上的那一个。** 它看着就是个
> 化学名，第 2 条会先命中、猜成 /iːn/；实际读 /əˈdrɛnələn/——词尾那个 -ine 完全不重读，
> 归第 4 条。它另有 `adrenalin` 不带 e 的拼法，正好跟这个读法对得上。
> 这个工具的词典也按 /ən/ 评测，猜成 /iːn/ 会记一处错。

**化学和药物名那一条最好记，也最实用**：这类词几乎清一色 /iːn/。

## 自检法

**照镜子看口型**——这是最直接的一条：

- **/iːn/** 的口型**从头到尾不变**：嘴角向两侧拉开、保持住，直到舌尖抵上齿龈收成 /n/
- **/aɪn/** 的口型**在变**：先张开（/a/），再收窄上滑（/ɪ/），才到 /n/

念 machine，盯着镜子里的嘴角。**动了就是念成 /aɪn/ 了。**

**摸下巴**——/aɪ/ 是双元音，下巴会先下沉再回收；/iː/ 是单元音，下巴基本不动。
手指搭在下巴上念 routine，下巴晃动就是踩坑。

## 对比训练

### 先在中文里感受"口型不变 vs 口型在变"

- **口型不变**：念「衣——」拉长，嘴角一直咧着不动 → 这就是 /iː/ 的状态
- **口型在变**：念「爱」，感受下巴先落再收 → 这就是 /aɪ/ 的状态

把这两种感觉分清楚之后再进英文，比直接背规则有效——你要练的不是知道，是**嘴角动没动**。

### 英文 minimal pairs

同样是 -ine 收尾，一边 /aɪn/ 一边 /iːn/，交替念：

| /aɪn/ | /iːn/ |
|---|---|
| fine /faɪn/ | **machine** /məˈʃiːn/ |
| line /laɪn/ | **routine** /ruˈtiːn/ |
| mine /maɪn/ | **marine** /məˈriːn/ |
| divine /dɪˈvaɪn/ | **caffeine** /kæˈfiːn/ |

念每一对时把手指搭在下巴上：左边那列下巴要动，右边那列不动。

### 最容易混的三对

- **wine** /waɪn/ ↔ **vaccine** /vækˈsiːn/
- **mine** /maɪn/ ↔ **marine** /məˈriːn/（只差一个音节，读法完全不同）
- **dine** /daɪn/ ↔ **dopamine** /ˈdoʊpəˌmiːn/

## 阶段拆解

以 machine 为例：

1. **只练词尾**：反复念 `/ʃiːn/`，对着镜子确认嘴角**全程不动**
2. **加前面的弱读音节**：`/mə/` + `/ʃiːn/`。第一个音节要**轻到几乎听不见**——
   重音在后面，念成"马-申"（两个音节一样重）就不对了
3. **完整词**：`/məˈʃiːn/`，手指搭下巴确认只下沉一次（在 /iː/ 上）
4. **进短语**：`washing machine`、`the machine is on`
5. **换词自测**：不看音标，念 routine、marine、caffeine、magazine——
   每念一个先问"嘴角该不该动"，再念出来

第 5 步是这篇的真正目的：这不是练某个音，是**改掉看到 -ine 就念 /aɪn/ 的反射**。
