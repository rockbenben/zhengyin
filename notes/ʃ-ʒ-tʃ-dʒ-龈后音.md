# she 不是「西」，cheap 不是「气普」——嘴唇要撅出来

**一句话结论：** 这四个音的分界动作是**嘴唇微微前突撅圆**。中文的「西」「七」嘴角是向两侧拉开的，「师」「吃」是舌尖后卷的——两组都不对。

> 中文有一堆听起来很像的音，所以这一条不是"没学过"，而是"学过了别的"。替身太顺手，反而更难改。

## 音标与定位

四个音，同一个舌位，两两成对：

| | 清（喉咙不震） | 浊（喉咙震） |
|---|---|---|
| **擦音**（可以一直发） | **/ʃ/** she、ship、wash、nation | **/ʒ/** measure、vision、usual、beige |
| **塞擦音**（先堵后擦） | **/tʃ/** cheap、chair、watch、future | **/dʒ/** jeep、jump、age、bridge |

音系学叫**龈后音（postalveolar）**——发音位置在齿龈**后方**，比中文的「西」靠后，又比「师」靠前。

## 常见误区

中文母语者有两套现成的替身，都不对：

- **用 x / j / q（「西」「几」「七」）**：she → 「西」、cheap → 「七普」。中文这三个是**龈腭音**，舌面整片贴向硬腭，**嘴角向两侧拉开**。听感偏尖、偏薄。
- **用 sh / zh / ch（「师」「知」「吃」）**：she → 「师」、jeep → 「知普」。中文这三个是**卷舌音**，舌尖向后卷起。听感偏"厚"、偏闷。
- **念成 /s/ 或 /z/**：she → "see"、measure → "mezzer"。摩擦位置太靠前了，这是模型最常报出来的一种。
- **/dʒ/ 和 /ʒ/ 分不开**：jeep 和 "zheep"。前者要先堵住再放开，后者一直擦。

## 发音原理

**四个音共用的舌位：**

- 舌尖或舌叶抬向**齿龈后方**（比发 /s/ 的位置往后一点点），舌尖**不向后卷**、舌面**不整片贴上硬腭**。
- 舌头两侧顶住上齿，气流集中从中间那道槽出去。
- **嘴唇微微前突、拢圆**——这是跟中文那两组最明显、也最好操作的差别。

**四个音的分别只有两个开关：**

| 开关 | 怎么做 |
|---|---|
| 喉咙震不震 | /ʃ/ /tʃ/ 不震；/ʒ/ /dʒ/ 震 |
| 先堵不堵 | /ʃ/ /ʒ/ 直接擦；/tʃ/ /dʒ/ 先用舌尖堵住齿龈，再放开成擦音 |

## 自检法

**照镜子看嘴唇。** 交替念中文「西」和英语 she：

- 念「西」时嘴角向两侧拉开（像微笑）。
- 念 she 时嘴唇应该**微微撅出来**，侧面看得见前突。

如果两次嘴形一样，说明你念的是中文那个音。**这是最快也最准的一条检查。**

**摸喉咙分清浊。** 拖长发 /ʃ/（像叫人安静的「嘘——」），手指按喉结，不震；不改口型加上声音变成 /ʒ/，震。来回五次。

**分擦音和塞擦音。** /ʃ/ 可以一直拖下去；/tʃ/ 拖不了——它必须先堵住。如果你能把 cheap 的第一个音拖成三秒，那你念的是 /ʃ/ 不是 /tʃ/。

**「嘘」是现成的起点**：中文里让人安静的那个「嘘——」，嘴唇是撅圆的，位置已经很接近 /ʃ/ 了。

## 对比训练

**先在中文里把三组分开。** 念这三个，注意**嘴唇**：

| | 嘴唇 | 舌头 |
|---|---|---|
| 中文「西」 | 向两侧拉开 | 舌面贴硬腭 |
| 中文「师」 | 自然 | 舌尖后卷 |
| 英语 she | **微微前突撅圆** | 舌叶抬向齿龈后方，不卷 |

三个连着念十遍，只盯嘴唇的形状变化。

**英文 minimal pairs —— /ʃ/ 对 /s/（位置够不够靠后）：**

| /ʃ/ | /s/ |
|---|---|
| she | see |
| ship | sip |
| shy | sigh |
| wash | was |

**/tʃ/ 对 /ʃ/（有没有先堵住）：**

| /tʃ/ | /ʃ/ |
|---|---|
| cheap | sheep |
| chair | share |
| chop | shop |
| watch | wash |

**/tʃ/ 对 /dʒ/（喉咙震不震）：**

| /tʃ/ | /dʒ/ |
|---|---|
| cheap | jeep |
| chin | gin |
| rich | ridge |
| batch | badge |

## 阶段拆解

1. **从「嘘」出发**：发中文的「嘘——」，嘴唇已经撅圆了。保持不动，这就是 /ʃ/ 的位置，拖三秒。
2. **配元音**：/ʃ/ + /i/ = she。慢速十遍，每遍都先摆好唇形再出声。
3. **加喉咙**：保持 /ʃ/ 的口型，中途让喉咙震起来 → /ʒ/。measure、vision 各十遍。
4. **加"先堵"**：舌尖抵住齿龈憋一下，再放开成 /ʃ/ → /tʃ/。cheap、chair 各十遍。
5. **四个连着**：ʃ - ʒ - tʃ - dʒ，慢速走一遍，确认唇形自始至终没散开。
6. **进句子**：「**She** **chose** a **cheap** **chair**.」「It's a **usual** **change**.」
