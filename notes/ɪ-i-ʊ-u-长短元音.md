# 长短元音是两个音——sit 不是短一点的 seat

**一句话结论：** `ɪ` 不是短一点的 `i`，`ʊ` 不是短一点的 `u`。差别在**舌位和肌肉松紧**，不在时长。把 sit 拖长不会变成 seat，只会变成拖长的 sit。

> 中文只有一个「衣」、一个「乌」，所以嘴里没有 `ɪ` 和 `ʊ` 的位置。这是**没学过**，不是听力问题。

## 音标与定位

四个单元音，两对。教材上叫紧元音（tense）和松元音（lax）。

| 松（lax） | 紧（tense） |
|---|---|
| **/ɪ/** sit、bit、ship、fill | **/i/** seat、beat、sheep、feel |
| **/ʊ/** book、full、pull、could | **/u/** boot、fool、pool、cooed |

「长短」这个叫法本身就在误导——它让人以为拖长就行。

## 常见误区

- **两个都念成中文的「衣」**：sit 和 seat 出口是同一个词，自己听不出区别。最常见。
- **靠拖长来区分**：seat 念成「衣——」，sit 念成「衣」。时长确实有差，但那是结果不是原因；把 /ɪ/ 拖长听起来仍然是 sit。
- **/ʊ/ 念成中文「乌」**：book 念成「布克」。中文的「乌」嘴唇突得很厉害，那是 /u/ 的口型。
- **词尾加音**：feel 念成「菲欧」——那是另一件事（词尾的暗 L），跟元音无关。

## 发音原理

**/i/（紧）** 舌面高高顶向硬腭前部，**嘴角明显向两侧拉开**，像在笑；口腔肌肉是绷着的。
**/ɪ/（松）** 从 /i/ 的位置**整个放松**：舌位略低、略往后退，嘴角回到自然状态，下巴微微松开。关键动作就是「松」。

**/u/（紧）** 舌根高高抬向软腭，**双唇用力撅圆并向前突出**，能夹住一支笔。
**/ʊ/（松）** 同样是放松版：舌位略低略前，唇形还是圆的但**不向前突**，只是自然拢起来。

四个音的分界全在「紧 vs 松」这一个动作上，不在长短。

## 自检法

**看嘴角，不听长短。**

- 对着镜子念 seat：嘴角应该明显向两侧拉开。再念 sit：嘴角**不该动**。如果两次嘴角一样，你念的是同一个音。
- 手指轻搭在两侧嘴角上念 seat / sit，感觉手指有没有被推开。

**看嘴唇突不突。**

- 念 boot：嘴唇撅圆并**向前突出**，侧面看得见。再念 book：唇是圆的，但**不前突**。
- 拿一支笔横放在唇前，念 boot 时嘴唇应该能碰到它，念 book 时碰不到。

**拖长测试（用来证伪"拖长就行"）**：把 sit 的元音拖到三秒。它还是 sit，不会变成 seat。如果你觉得变了，说明你在拖长的同时偷偷把嘴角拉开了——那才是真正起作用的动作。

## 对比训练

**先在中文里感受「紧」和「松」。** 中文里没有 `ɪ` 和 `ʊ`，所以给不出中文的 minimal pair——能给的是那个**肌肉动作**：

念中文「衣」，感觉嘴角是绷紧向两侧的。保持发声，把嘴角和下巴**完全放松**，让声音塌下去一点——那个含糊的音就在 `ɪ` 附近。
念中文「乌」，嘴唇是向前突的。保持发声，把嘴唇**收回来**、只留自然的圆——那就是 `ʊ`。

**英文 minimal pairs：**

| /ɪ/ | /i/ |
|---|---|
| sit | seat |
| bit | beat |
| ship | sheep |
| fill | feel |
| live（住） | leave（离开） |
| his | he's |

| /ʊ/ | /u/ |
|---|---|
| full | fool |
| pull | pool |
| could | cooed |
| look | Luke |

**最容易出事的一对是 live / leave**：意思差得很远，而且都是高频词。

## 阶段拆解

1. **只练嘴角**：不出声，对着镜子在「拉开」和「放松」之间来回切换十次，看清楚两个位置。
2. **加声音**：保持嘴角拉开发 /i/，保持放松发 /ɪ/，各拖三秒，确认两个音色确实不同。
3. **配辅音**：s + /i/ + t = seat，s + /ɪ/ + t = sit。慢速交替念十遍，每次都先摆好嘴角再出声。
4. **成对进句**：「Have a **seat**.」/「**Sit** down.」；「I **live** here.」/「I **leave** here.」
5. **换到唇形那一对**：把 1–4 重做一遍，把「嘴角拉开/放松」换成「嘴唇前突/收回」，词换成 fool / full。
