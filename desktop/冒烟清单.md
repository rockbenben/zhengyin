# 桌面版冒烟清单

这些是 jsdom / 单测覆盖不到的部分：窗口、系统权限、真实进程树、安装包、更新。
按顺序在真机上走一遍；出现「该看到什么」以外的结果就是没通过。

## 准备

```bash
npm run build
npm run fetch-runtime
npm run check:package
npm run smoke:package
npm run dist:desktop
```

产物在 `desktop/release/`：安装版 `zhengyin-<版本>-win-setup.exe`，免安装版
`zhengyin-<版本>-win.zip`（`dist:desktop:zip` 产出在 `desktop/release-zip/`）。

> **Windows 打包偶尔会死在 `EBUSY ... default_app.asar`。** 这是工作区里的扫描器
> （编辑器 / AI 宿主）临时持有刚解压的文件，不是配置错。换一个从没打过包的新输出目录
> （例如 `--config.directories.output=desktop/release/pkg1`），或者把产物输出到仓库外，
> 再跑一次。CI 的干净 runner 上不会出现。

## 1. 全新首次启动

- [ ] 双击安装版或解压后的 `正音.exe`。
- **该看到什么**：首启对话框（旧文件夹 / 导入备份 / 全新开始）。选「全新开始」后，
  一两秒内出窗口，不是白屏。建 `click`、录音、评测出结果。关掉重开，数据还在。

## 2. 首启选旧文件夹

- [ ] 准备一个旧的正音文件夹（含 `data/`、`notes/`），首启选它。
- **该看到什么**：旧的词条、旧笔记、发音档案都在；原文件夹**没有被复制或移动**。
  数据目录就是它。

## 3. 首启导入备份

- [ ] 首启选「导入备份」，选 `/api/backup` 导出的 JSON。
- **该看到什么**：词条、录音判定、复习进度回来；界面**明确说**档案和笔记不在备份里。

## 4. 首启选错文件夹

- [ ] 选一个空文件夹。
- **该看到什么**：当场说「不像正音的数据根」，让重选；不进主窗口、不建空库。

## 5. 关窗口 = 退出

- [ ] 打开窗口，关掉。
- **该看到什么**：窗口消失；任务管理器里没有残留的 `node.exe` / `uv.exe` / `python.exe`
  子进程；端口不再监听。重开正常。

## 6. 识别服务首次准备

- [ ] 全新安装后直接录音。
- **该看到什么**：状态条显示「正在启动」，展开日志能看到「模型不在本地缓存里，开始获取」
  和下载进度；变成 ready 后录音能出「第几个音发成了什么」。首次约 1.2GB，之后十几秒。

## 7. 识别服务出错与重启

- [ ] 把 `resources/runtime/uv.exe` 临时改名（或断网）。
- **该看到什么**：状态条显示错误 + 日志 + 「重启识别服务」；点重启能恢复；其他功能照常。
  改回名字后重开应用也能恢复。

## 8. 麦克风权限

- [ ] 真录一次音。
- **该看到什么**：波形、计时、自动评测都正常。在系统设置里拒绝麦克风后再试，
  界面给的是能照做的中文，不是空白或英文报错。

## 9. 数据锁

- [ ] 在仓库里先 `npm start`，再启动桌面版并选同一个文件夹。
- **该看到什么**：桌面版明确说「这个数据文件夹正被另一个正音进程使用（pid …）」，让重选；
  关掉 `npm start` 后能进。

## 10. 单实例

- [ ] 应用开着时再双击一次 exe。
- **该看到什么**：只把已有窗口拉到前台并聚焦，不出现第二个服务或第二个窗口。

## 11. 外链

- [ ] 在 `data/notes/` 放一篇带 `https://example.com` 链接的笔记，打开它并点链接。
- **该看到什么**：系统浏览器打开；应用本身没被导航走，也没弹出第二个 Electron 窗口。

## 12. 菜单

- [ ] 打开「文件 → 打开数据文件夹」；NSIS 版再看「帮助」。
- **该看到什么**：数据文件夹真的打开；NSIS 版有「检查更新」「自动检查更新」（默认关）；
  zip 版**没有**更新项；开发模式多一个「开发者工具」。

## 13. SmartScreen

- [ ] 第一次双击未签名的安装包。
- **该看到什么**：SmartScreen 提示；按 README 的「更多信息 → 仍要运行」能继续。

## 14. 升级（只在 NSIS 安装版）

- [ ] 装 vN，再装 vN+1。
- **该看到什么**：数据保留；「重启以完成更新」能正常收尾。zip 版不做自动更新验证，
  升级方式是解压覆盖后重新打开。

---

## 数据位置

- 全新开始：`%APPDATA%\zhengyin\app`（`data/`、`notes/`、`.env` 都在里面）。
- 选了旧文件夹：就是那个文件夹。
- 服务日志：`%APPDATA%\zhengyin\logs\server.log`。
- 桌面设置：`%APPDATA%\zhengyin\desktop-settings.json`；更新偏好：
  `%APPDATA%\zhengyin\update-prefs.json`。
